# 案例 06 · 灰色预测与马尔可夫修正

> GM(1,1) 全链路 + GM(1,N) / DGM(2,1) / Verhulst 选型 + markov_chain + 灰色-马尔可夫修正

## 这个案例解决什么

小样本预测类题目的标准链路。**前端**：把月度宽表整理成年度序列，做**级比检验**，
用 **GM(1,1)** 拟合与外推，再按训练期月份占比把年度预测**分摊回月**，
并用**配对 t 检验**检验预测与真实的差异。**中段**：并列讲清 GM(1,N) / DGM(2,1) /
Verhulst 三种灰色模型的**适用数据形态**。**后端**：`markov_chain()` 做状态转移，
`GM11_markov()` 用残差状态把灰色预测的"波动短板"补上。

数据选得很妙：**2003 年 SARS** 让北京接待海外游客数断崖式下跌，
正好演示"灰色模型只能外推既有趋势、无法预见突变"这一核心局限。

## 数据

`../data/北京市接待海外旅游人数.xlsx`：1997–2003 年**逐月**接待海外游客数（万人，
`每年一行 × 12 个月列` 的宽表），共 84 个月。

## 覆盖的包函数

`GM11` · `GM1N` · `DGM21` · `verhulst` · `markov_chain` · `GM11_markov`

## 流程

1. 宽表 → 长表 → 按年汇总；训练期取 1997–2002（6 期），2003 留作检验；
2. `GM11()`（自动做级比检验）→ 看 `lambda` / `rng` / `fitted` / `pnext`，
   用 `f(1:9)` 做多期外推；
3. **月份占比只用训练期算**，把 `pnext` 分摊到 12 个月，与 2003 真实值做配对 t 检验；
4. 灰色模型族选型表 + `GM1N()` / `DGM21()` / `verhulst()` 实例；
5. `markov_chain()` 状态转移 + `GM11_markov()` 修正；
6. 出图：月度序列（标出 SARS 区间）/ GM11 拟合外推 vs 实际 / 2003 逐月对比 /
   灰-马尔可夫修正。

## 关键决策点

- **月份占比必须只用训练期数据算**，否则会把 2003 年的真实信息带进分配（数据泄漏）；
- **灰色模型适合 4–15 期的小样本**；样本充足时应上时间序列模型（`ts_*`）；
- **模型选型看数据形态**：单调近指数 → GM(1,1)；非单调摆动 → DGM(2,1)；
  饱和 S 形 → Verhulst；被多因素驱动 → GM(1,N)；
- **灰色模型抓趋势、马尔可夫抓波动**，二者互补；
- **级比检验不通过**时应先做平移变换或改用其他模型，不要硬跑。

## 踩过的坑

1. **`markov_chain()` 的 `trans_mat` 是 contingency `table`、`pred_probs` 是 `matrix`**。
   `as.data.frame(table)` 会把方阵**摊成长表** `Var1/Var2/Freq`；`as_tibble(matrix)` 会
   静默丢行名。**0.0.14 起 `trans_mat` 的 `dimnames` 已命名为 `from`/`to`**，直接
   `as_tibble(x, rownames = ...)` 不再报 `Names can't be empty`（但会把维度名当列名、
   产生重复列）。本案例仍用最稳的三步走：`matrix(as.numeric(x), nrow(x), dimnames(x))`
   还原矩阵 → `as.data.frame()` → `rownames_to_column()`。
2. **`as_tibble()` 会静默丢弃行名**。若要用行名当第一列，必须
   **先 `rownames_to_column()` 再 `as_tibble()`**，顺序反了会得到 `1,2,3`。
3. **`GM11_markov()` 返回表的末尾 `T+1 / T+2 / T+3` 三行 `Raw` 为空**（外推期没有真值），
   算误差均值要 `na.rm = TRUE`，作图要先 `filter(!is.na(Raw))`。
4. **`markov_chain()` 返回字段是 `trans_mat / pred_probs / pred_states / pi_final`**，
   起始状态由 `s0` 指定，`pred_states` 是逐步**最可能**状态。

## 实测结论（本案例数据）

- 级比检验：`lambda ∈ [0.8541, 1.0548]`，容覆盖区间 `[0.7515, 1.3307]` → **通过**；
- GM(1,1) 拟合平均相对误差 **2.31%**；
- 2003 年实际 190.29 万人，远低于模型预测（SARS 冲击），配对 t 检验差异显著；
- 灰-马尔可夫修正把拟合期平均绝对误差从 **5.065** 降到 **3.167**。
