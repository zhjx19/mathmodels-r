# 案例 03 · DEA 效率评价

> CCR / BCC × 投入 / 产出导向四组合 + 超效率 + 带非期望产出 SBM + 规模效率 + 面板 Malmquist

## 这个案例解决什么

效率评价类题目的完整工具箱。截面部分把**径向 DEA 的四种组合**都跑一遍，再用
**超效率**把一堆并列为 1 的 DMU 分出高下，用 **SBM** 纳入**非期望产出**（医疗废弃物），
并算**规模效率**判断规模报酬。面板部分用 **Malmquist 指数**把全要素生产率变化
分解为效率变化（`ec`）与技术进步（`tc`）。

## 用户大概会这么问

- "DEA 怎么算效率？CCR 和 BCC 有什么区别？"
- "投入导向和产出导向选哪个？"
- "一堆 DMU 效率都是 1，怎么继续排名？"（→ 超效率）
- "模型要考虑非期望产出（污染、废弃物）怎么办？"（→ SBM）
- "面板数据怎么做全要素生产率？"（→ Malmquist）

## 数据

- `../data/hospital.csv`：31 个省的医院投入产出（床位数 / 卫技人员 → 诊疗人次数 /
  入院人数 / 医疗废弃物）——截面，含非期望产出；
- `../data/economy.csv`：31 省 5 年（2005–2009）工业面板（资本 / 劳动 → 工业总产值）
  ——长格式，第 1 列 `DMUs`、第 2 列 `Period`。

## 覆盖的包函数

`basic_DEA` · `super_DEA` · `basic_SBM` · `super_SBM` · `malmquist`

## 流程

1. 径向 DEA 四组合：`crs/io`、`crs/oo`、`vrs/io`、`vrs/oo`；
2. 超效率（`super_DEA`）打破"效率 = 1"的并列，**NA 用标准 BCC 效率补齐**，
   并出一张 CRS / VRS × 两种导向的**不可行性对照表**（说明 NA 什么时候才会出现）；
3. SBM 纳入非期望产出；
4. 汇总表 + 规模效率 = `ccr_in / bcc_in`，据此判规模报酬（irs / drs / crs）；
5. Malmquist：按 `period` + DMU 计算并分解；
6. 出图：效率对比 / 规模效率 / Malmquist 分布。

## 关键决策点

- **导向选择**：投入导向回答"给定产出下能省多少投入"，产出导向回答
  "给定投入下能增多少产出"，取决于管理含义，论文必须交代；
- **DMU 数量要够**：经验法则是 DMU 数 ≥ 投入×产出指标数的 2~3 倍，否则大量
  DMU 会被判定有效（本案例 31 个 DMU 对应 2 投入 × 2 产出，尚可）；
- **超效率的 NA 必须处理**：无可行解是 **VRS 超效率**的固有现象（凸组合够不到极端 DMU），
  直接排序会**漏掉**这些 DMU；补齐或视理论需要改用 `crs` 都可，但必须在论文里交代；
- **规模效率 = CRS 效率 / VRS 效率**，>1 为规模报酬递增、<1 为递减。

## 踩过的坑

1. **返回字段是 `efficiencies`（复数），不是 `efficiency`**。写 `res$efficiency`
   会得到 `NULL`，后续静默出错。
2. **`basic_SBM()` 在 v0.0.14 是非导向模型，不能传 `orientation`**，否则报
   `SBM models are non-oriented; 'orientation' is not applicable.`
   ⚠️ `mathmodels-book` 的 `dea.qmd`（截至 2026-10 的书稿快照）里传了 `orientation = "oo"`，**照抄会报错**。
3. **DEA 家族的 `data` 必须是 data.frame 且第 1 列是 DMU 名**，传 `matrix` 直接报错；
   读中文列名 CSV 要 `check.names = FALSE`，否则括号会被换成点。
4. **超效率返回的 NA 要显式补齐**（本案例 `io + vrs` 下 2 个 DMU 无可行解），否则排名不全。
   （0.0.14 起 `basic_DEA` / `super_DEA` 在求解器失败时会汇总 `warning`、列出 DMU 名，
   正常路径保持安静——但告警不会替你填值。）
5. **NA 只在 `rts = "vrs"` 下出现，`crs` 永不失效**——这不是数据错，是 VRS 超效率的
   固有不可行性：把该 DMU 移出参考集后，其余 DMU 的**凸**组合够不到它的产出水平 ⇒
   LP 不可行；`crs` 的锥形包络可以无限放大，所以恒有解。   本案例的 `03_超效率不可行性对照` 表把四种组合列齐了——实测 **io+vrs 2 个（广东、山东）、
   oo+vrs 1 个（西藏）、crs 两种导向 0 个**。注意**两种导向的失败单元并不相同**，
   不能想当然认为"都是那些极端 DMU"。
   用 6 个 DMU 就能手工复现：`x1=c(2,3,4,5,3,4)`、`x2=c(3,4,5,6,4,5)`、
   `y1=c(8,9,10,12,11,13)`、`y2=c(5,6,7,8,7,9)`，
   `io+vrs` 失败于 F、`oo+vrs` 失败于 A。（这个触发条件是本 skill 反馈给上游后定位的——
   作者原先认为"难以复现"，实为原搜索用 2 投入 1 产出 + 均匀分布，结构上产生不了极值点。）

## 实测结论（本案例数据）

- BCC 投入导向下有效（效率 = 1）的省份 11 个；超效率排名前 5：西藏、云南、上海、福建、四川；
- 平均规模效率 0.9611，25 个 DMU 规模无效率；
- Malmquist 全样本 `mi` 均值 **1.0665**（>1，生产率提升），分解 `ec = 1.0046`、
  `tc = 1.0615` —— **提升主要来自技术进步而非效率改善**。
