# 案例 02 · 模糊综合评价（FCE）

> 11 个隶属函数全族 + 模糊合成算子 + 去模糊化 + 模糊统计法 + 数据驱动的隶属函数拟合

## 这个案例解决什么

模糊综合评价的**全链路**，且刻意把"最容易写错"的三处都过一遍：
① 隶属函数的**参数量各不相同**（2~4 个），传错直接报错；
② 合成算子有 **5 种**，选哪个会改变结论；
③ 隶属矩阵既可以"用隶属函数算"，也可以"从评委打分统计出来"。
最后还做了一件更有意思的事：用 **129 位专家给出的"青年人"年龄区间**，
反推出一条数据驱动的隶属函数。

## 用户大概会这么问

- "模糊综合评价怎么做？步骤是什么？"
- "隶属函数怎么选？三角、梯形、高斯、S 型有什么区别？"
- "评语集怎么去模糊化成一个分数？"
- "专家打分怎么汇总成隶属矩阵？"
- "为什么 `fuzzy_eval(..., 5)` 报 `missing value where TRUE/FALSE needed`？"（→ 见坑 2）

## 数据

- `../data/youth.xlsx`（129 位专家给出的"青年人"年龄**区间**）——第 ⑤ 节用；
  ⚠️ 区间分隔符是 **U+2212 减号 `−`**，不是 ASCII 连字符，`separate()` 要用 `"\u2212"`；
- 其余三节用构造数据（耕作方案、评委打分），无需外部文件。

## 覆盖的包函数

`mf_tri` · `mf_trap` · `mf_gauss` · `mf_gbell` · `mf_gauss2` · `mf_sigmoid` ·
`mf_dsigmoid` · `mf_psigmoid` · `mf_z` · `mf_pi` · `mf_s`（**11 个，全部零示例**）·
`plot_mf` · `compute_mf_funs` · `compute_mf` · `fuzzy_eval` · `defuzzify`

## 流程

1. **① 隶属函数族**：11 个 `mf_*` 逐个调用，落一张"参数量 + 参数值 + 实际值域"表；
2. **② `compute_mf_funs` / `compute_mf`**：由阈值 knots 生成各等级隶属函数，
   把单个指标值转成"属于各评语的隶属向量"；
3. **③ 完整 FCE**：耕作方案选优（甲 / 乙 / 丙），5 因素 × 4 评语（差 / 中 / 良 / 优），
   合成 → 去模糊化 → 评分排名；并做**5 种合成算子的灵敏度对比**；
4. **④ 模糊统计法**：从评委打分直接统计出隶属矩阵（分组计数即隶属度）；
5. **⑤ 数据驱动**：由 129 位专家的区间，拟合"青年人"隶属函数。

## 关键决策点

- **评语量化分必须升序**：`scores <- c(30, 60, 75, 90)` 对应 差/中/良/优，
  顺序写反会得到反向结果且不报错；
- **负向指标要用固定阈值平移**（`5 - quality` / `80 - labor`），
  不要用"样本最大最小"——那样 3 个方案就不在同一把尺子上了；
- **合成算子要么在论文里交代清楚，要么给灵敏度分析**：算子 1（取小取大）是
  "主因素决定型"，算子 3（乘加）是"加权平均型"，结论可能不同；
- `compute_mf_funs(th)` 返回函数个数 **= `length(th)`**（不是 `+1`），别搞错等级数。

## 踩过的坑

1. **`mf_dsigmoid` 是唯一可能取负值的隶属函数**（两个 sigmoid 之差）。
   实测 `params = c(1, 1.5, 9, 1.5)` → 值域 `[-0.375, 0.375]`；理论上界 ±1，
   实际到达多少取决于 params。**不能按 `[0,1]` 用**。（0.0.14 起 Rd 已订正——
   原先它与其余 10 个 `mf_*` 被一并声明为 `[0,1]`。）
2. **`fuzzy_eval(w, R, type = 5)` 曾会在"某评语等级在所有指标上隶属度全为 0"时崩**
   （**0.0.14 已修**）：均衡平均型的归一化分母 `r0 = sum(R[j,])` 取的是 R 的**行和**，
   某行全 0 则除零得 `NaN`，于是 `if (sum(B) == 0)` 拿到 `NA` 报
   `missing value where TRUE/FALSE needed`（包自带文案在 NaN 情形下反而不会触发）。
   修法是"不可能发生的等级"记 0：本例方案乙没有"差"的可能，该等级即记 0、其余归一。
   脚本里留了一条 `stopifnot(!length(bad))` 防回退。
3. **控制台噪声**：`read_excel(col_names = FALSE)` 与 `as_tibble(matrix, .name_repair=...)`
   都会刷一堆 `New names:`，用 `suppressMessages()` 包一下，保持 `console.txt` 干净。
4. **`youth.xlsx` 的分隔符是 U+2212**，`separate(x, c("x1","x2"), sep = "\u2212", convert = TRUE)`。
