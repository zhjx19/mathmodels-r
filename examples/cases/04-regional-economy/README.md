# 案例 04 · 区域经济：不平等测度与产业集聚

> 基尼系数 + 洛伦兹曲线 + 泰尔指数三种分解 + 区位商 LQ + HHI + EG 指数

## 这个案例解决什么

"区域差距 / 产业集聚"类题目的主力工具。**不平等测度**部分给出基尼系数（可按行业、
按省份批量算）与洛伦兹曲线；**泰尔指数**部分把总差异拆成"组间 + 组内"，
并同时演示**单分组、两交叉、两嵌套**三种分解。**集聚测度**部分用区位商看专业化、
用 HHI 看集中度、用 EG 指数看空间集聚（已扣除产业结构本身的影响）。

## 用户大概会这么问

- "基尼系数怎么算？怎么按行业 / 地区分别算？"
- "泰尔指数怎么分解成组间和组内？交叉分解和嵌套分解有什么区别？"
- "洛伦兹曲线怎么画？"
- "区位商怎么算某省某产业的专业化程度？"
- "HHI 和 EG 指数有什么区别？"

## 数据

- `../data/income.xlsx`：2014–2023 年 × 31 省 × 8 行业的平均工资与就业人数（2480 行）
  ——**平均量数据，算基尼必须传 `pop` 权重**；
- `../data/industry.xlsx`：2015–2024 年 × 31 省的 GDP 与三次产业增加值（310 行）。

## 覆盖的包函数

`gini` · `theil` · `theil_g` · `theil_g2_cross` · `theil_g2_nest` · `LQ` · `HHI` · `EG`

## 流程

1. **基尼系数**：`gini(y, pop)` 按 `(年份, 行业)` 与 `(年份, 地区)` 分组批量算；
2. **洛伦兹曲线**：按**人均值**排序后做累计曲线，并叠加对角线与基尼系数；
3. **泰尔分解**：`theil_g`（单分组）/ `theil_g2_cross`（两交叉）/
   `theil_g2_nest`（嵌套），统一扁平化成 `年份 | 成分 | 项 | 值` 长表；
4. **区位商**：补全国行 → `LQ()` → 热图；
5. **HHI / EG**：集中度与空间集聚对比。

## 关键决策点

- **平均量数据必须人口加权**：`gini(平均工资, 就业人数)`；只传 `平均工资` 算出来
  是不平等程度的错误口径；
- **洛伦兹曲线要按"人均值"排序**，不是按平均工资或按总量；
- **交叉 vs 嵌套分解不是一回事**：交叉分解两个维度独立（可能一个省跨多个区域），
  嵌套分解要求 `group2` 严格内含于 `group1`（地区内含于区域），选错模型结论会错；
- **贡献率不能整体求和**：单/交叉分解只有 `Tb + Tw = 1`；嵌套分解是
  `Tb_g1 + Tb_g2 + Tw = 1`。

## 踩过的坑

1. **⭐ 最危险：`LQ()` 要求每组第一行是"全国合计"行**。
   源码是 `quotient = function(x) x[-1] / x[1]`——它拿组内第一行当分母，并把该行
   **从输出中删掉**。若只传 31 个省，它会**把某个真实省份当成分母用**并删掉它：
   **不报错、结果看着也合理，但数值全错**。做法：按年份汇总出全国行，
   加 `U+0001` 控制字符让它排在各组第一，合并 → 排序 → 调 `LQ()`，
   并用 `stopifnot(grepl("全国", first_rows))` 守卫 + 手工公式对拍。
2. **泰尔函数参数是列名字符串，不是列向量**：`theil_g(data, group, y, pop)`。
3. **`theil_g2_nest` 的 `ratio` 与 `theil` 不等长**（实测泰尔指数 39 项 / 贡献率 43 项）：
   `ratio` 末尾多出各一级分组的"组内总贡献"块，**0.0.14 起命名为 `东北.within` 等**
   （此前该块与组间项**重名**、而且**取值是错的**——`summarise()` 里 `Rwi` 命中环境中的
   全长向量，分组失效，每组拿到的都是全局合计）。两向量仍**不能按名或按位置对齐**；
   统一转长表最稳。
4. **泰尔表的列名是 `T` / `Tb` / `Tw`**，不是"组间""组内"，`select()` 时要写真实列名。
5. **`grepl` 的 `pattern` 不能传向量**：`stopifnot(all(...))` 里如果 pattern 是长度 >1
   的向量会报 `argument 'pattern' has length > 1`，要先 `pull()` 成向量。

## 实测结论（本案例数据）

- 2023 年各行业**省份间**工资基尼系数：制造业 0.559、建筑业 0.543、信息业 0.483、
  商贸 0.398、科研 0.394、教育 0.370、医疗 0.353、金融业 0.337；
- 抽验：2024 年上海第三产业区位商 手工 = `LQ()` = 1.384729（对拍通过）；
- 贡献率自校验：`Tb + Tw = 1`，最大偏差 < 1e-8。
