# 案例 01 · 多级指标体系综合评价

> 熵权 / CRITIC / 变异系数 三种客观赋权 + AHP 主观赋权 → 博弈论组合赋权 → 多级合成 → TOPSIS 排名

## 这个案例解决什么

典型"评价类"赛题的标准骨架：**一套多级指标体系**，先做**三级指标赋权**，向上合成
**二级得分**，再给二级指标定权，最后合成**一级综合得分**并**排名**。
这里刻意把三种客观赋权都跑一遍，还加了 AHP 做主观对照——因为"赋权方法怎么选、
怎么组合"是评价类题目最常见的失分点。

## 用户大概会这么问

- "多级指标体系怎么做综合评价？"
- "熵权法和 AHP 怎么结合？组合赋权怎么写？"
- "CRITIC 法 / 变异系数法怎么赋权？"
- "TOPSIS 怎么按年份分组排名？"
- "二级指标得分算出来是 8000 多分，是不是乘错了？"（→ 见下方坑 2）

## 数据

`../data/employment-quality.xlsx`（就业质量，30 个地区 × 3 年 × 11 个三级指标）

- `Sheet1`：指标数据，**首行是合并表头**（一级 / 二级 / 三级指标各占一行，读入后需注意）；
- `Sheet2`：指标体系（一级 1 个 / 二级 5 个 / 三级 11 个）。

## 覆盖的包函数

`weight_entropy` · `weight_critic` · `weight_cv` · `AHP` · `combine_weights` ·
`linear_sum` · `topsis` · `rescale`

> `weight_entropy` / `weight_critic` / `weight_cv` 在常用素材（书稿、建模文章）里**缺少可直接
> 运行的示例**，这是本案例的重点覆盖对象。

## 流程

1. 读数据、读指标体系（三级指标列名 = 数据第 3 列起）；
2. 三级指标分别用**熵权 / CRITIC / 变异系数**赋权，对比权重分布；
3. 用三级权重 → `linear_sum()` 合成**二级指标得分**；
4. 二级指标权重的定法：熵权（客观）与 `AHP()`（主观）→ `combine_weights()` 组合；
5. `linear_sum()` 合成**一级综合得分**；
6. `topsis()` 按年份分组算相对接近度，逐年排名；
7. 出图：三级指标权重对比 / 二级得分走势 / TOPSIS 排名。

## 关键决策点

- **客观 vs 主观赋权必须角色清晰**：熵权表达"信息量"，AHP 表达"政策偏好"，
  组合才有意义；否则两个同源客观方法叠加不产生新信息；
- **组合权重的机理**是博弈论（找纳什均衡点使各权重方案偏离最小），不是简单加权平均；
- **TOPSIS 的分组**：跨年比较时按年份分组各自归一化，否则年份间水平差异会污染排名。

## 踩过的坑

1. **`nest(.by = 年份)` 后嵌套表的第一列不再是原来的第 1 列**。年份被提到外层后，
   嵌套表里第一列是「地区」。此时用 `d[-(1:2)]` 位置下标取指标，会**少取一列**
   → `topsis()` 报 `index must have length equal to ncol(X)`。
   正确做法：`IND <- names(df)[-(1:2)]`，再用 `d[IND]` 按列名取。
2. **`weight_entropy()$s` 已在 0–100 量纲**（本案例实测二级得分 10.02 ~ 97.89），
   **不要再乘 100**，否则得分虚高到几千分。
3. **`topsis()` 的 `index` 只认 `"+"` / `"-"`，且不能带 `NA`**；赋权族（`weight_*`）
   反而允许 `NA`（表示已归一化）。两套约定别混。
